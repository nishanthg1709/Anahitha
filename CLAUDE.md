# ANAHITHA project rules
- Healthcare AI web app with 3D companion Dr. Anahitha. Strict zero-cost budget; never add paid services.
- Frontend: React + Vite, JavaScript (no TypeScript), Tailwind, Framer Motion, Lucide, react-three-fiber.
- Backend: Python 3.12, FastAPI, Pydantic, google-genai SDK. Supabase for auth/DB.
- Never expose API keys; use .env files and keep them out of git.
- English-only text and voice.
- Never diagnose, prescribe, or claim to dispatch emergency help.
- Emergency detection must be rule-based and run before any AI call.
- I am a learning student: explain what you do simply, run commands to verify, and never claim something works until tested.
- Colours: lavender #E9E2F8, #B9A5E8; plum #3A2A5E; rose #F28DB2; blush #FFD9E6; emergency red #D92D3F only for emergencies.
